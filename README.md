## Overview

This repository documents my enterprise Windows Server lab built as part of my networking studies.

The objective was to design and administer a Windows Server environment that mirrors common enterprise infrastructure, including Active Directory, DNS, DHCP, virtualization, PowerShell administration, backup, and disaster recovery.
